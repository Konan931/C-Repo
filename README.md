# C Utility Functions

Dieses Projekt umfasst eine Sammlung nützlicher C-Funktionen und Module zur Verarbeitung von Zeichenketten, Hashes, Dateioperationen, mathematischen Berechnungen und mehr. Es enthält auch grundlegende Funktionen zur Überwachung von Speicheroperationen und Threads.

## Hauptmodule:

1. **string_utils** - Zeichenkettenoperationen wie Kopieren, Anhängen und Umkehren von Strings.
2. **hash_utils** - Implementierung von Hash-Funktionen wie DJB2 und FNV-1a.
3. **file_utils** - Dateioperationen wie Lesen und Schreiben von Dateien.
4. **memory_utils** - Speicheroperationen mit Sicherheitsprüfungen.
5. **math_utils** - Grundlegende mathematische Operationen wie Quadratwurzel und Potenzen.
6. **hex_octal_utils** - Umrechnung von Dezimalzahlen in Hexadezimal- und Oktalformate.
7. **error_handling** - Fehlerbehandlungsfunktionen für Ausnahmen und Warnungen.
8. **thread_utils** - Thread-Verwaltung mit `pthread`.
9. **data_structures** - Implementierung grundlegender Datenstrukturen wie Stack.

## Nutzung:

- Alle Funktionen können durch Einbinden der entsprechenden Header-Dateien verwendet werden.
- Die Beispiele im Hauptprogramm (main.c) zeigen, wie man die Funktionen miteinander kombiniert.
